# Boat_Physics_Simulator

Authors: Emil Winroth, Johannes Ledendal & Casper Turesson

A simple simulation of a boat on open water made with an early version of [Windal Renderer](https://github.com/Winroth13/Windal_Renderer). Created as the final project for the course Physics for Game Engineering.

It includes gravity, buoyancy, drag, wing effect, pitch rotation and turning. The resulting forces can be seen in the inspector.

# Controls

WS - Increase/Decrease throttle

AD - Turning

RMB - Hold to rotate camera using mouse movement

Arrow Keys - Rotate camera
